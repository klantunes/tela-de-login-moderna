# Tela de Login Moderna
Projeto de uma tela de login moderna desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades
- Login social (Google, Facebook e LinkedIn)
- Mostrar/Ocultar senha
- Design responsivo
- Efeito Glassmorphism
- Animações e efeitos visuais
- Interface moderna

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
- Font Awesome

## Objetivo
Este projeto foi desenvolvido para praticar conceitos de Front-End, incluindo layout responsivo, estilização avançada com CSS e interatividade com JavaScript.
